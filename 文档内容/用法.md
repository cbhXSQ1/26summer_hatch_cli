# Hatch 使用手册

## 安装

```powershell
cd E:\summerschool
python -m venv venv
venv\Scripts\pip install -e .
```

## 快速开始

### 1. 录入 API Key

```powershell
venv\Scripts\python.exe -m hatch.cli key set
# 请输入 deepseek 的 API Key: sk-xxxxxxxxxxxxxxxx
# 已保存 deepseek 的 API Key
```

支持多个供应商：

```powershell
venv\Scripts\python.exe -m hatch.cli key set --provider glm
venv\Scripts\python.exe -m hatch.cli key set --provider claude
```

### 2. 配置模型

编辑 `hatch.yaml`：

```yaml
llm:
  provider: deepseek          # deepseek | glm | claude
  model: deepseek-v4-pro      # 模型名

loop:
  max_rounds: 3               # 最大修正轮次
```

可选模型：

| 供应商 | provider | 模型 |
|--------|----------|------|
| DeepSeek | `deepseek` | `deepseek-v4-pro`、`deepseek-reasoner` |
| 智谱 GLM | `glm` | `glm-5.2`、`glm-4-plus` |
| Anthropic | `claude` | `claude-sonnet-4-20250514`、`claude-opus-4-20250514` |

### 3. 运行

```powershell
venv\Scripts\python.exe -m hatch.cli run "写一个 add 函数到 app.py"
```

## 命令参考

### `run` — 执行任务

```powershell
venv\Scripts\python.exe -m hatch.cli run [--cwd <目录>] <任务描述>
```

| 选项 | 说明 |
|------|------|
| `--cwd` | 指定工作目录（默认当前目录）。目录不存在则自动创建 |

**示例**：

```powershell
# 在当前目录工作
venv\Scripts\python.exe -m hatch.cli run "创建一个 calculator.py"

# 指定目录
venv\Scripts\python.exe -m hatch.cli run --cwd D:\my_project "写一个 app.py"

# 中文任务
venv\Scripts\python.exe -m hatch.cli run "修复 test_calc.py 中的断言错误"
```

Agent 会自动：
1. 读取你指定的文件
2. 修改代码
3. 运行 pytest 测试
4. 如果测试失败，分析错误原因，重新修正
5. 最多修正 3 轮（可在 `hatch.yaml` 中调整）

### `session` — 会话管理

每个工作目录维护独立的对话历史，存储在 `.hatch/sessions/` 下。

```powershell
# 列出所有对话 (* 标记当前选中)
venv\Scripts\python.exe -m hatch.cli session list --cwd D:\my_project

# 开新对话
venv\Scripts\python.exe -m hatch.cli session new --cwd D:\my_project

# 切换到指定对话
venv\Scripts\python.exe -m hatch.cli session use --cwd D:\my_project <会话ID>

# 查看当前对话信息
venv\Scripts\python.exe -m hatch.cli session info --cwd D:\my_project
```

**逻辑**：
- 新目录首次 `run` 自动创建新对话
- 同一目录下后续 `run` 默认延续最新更新的对话（按 `updated` 排序），**不会自动切到其他对话**
- 需要切换时显式使用 `session use`
- 新开终端窗口或切换目录默认新对话

**示例流程**：

```powershell
# 1. 在 D:\my_project 开始工作
venv\Scripts\python.exe -m hatch.cli run --cwd D:\my_project "写 app.py"
# → 新对话: a1b2c3d4e5f6

# 2. 继续同一对话
venv\Scripts\python.exe -m hatch.cli run --cwd D:\my_project "加 test_app.py"
# → 继续对话: a1b2c3d4e5f6

# 3. 开新对话
venv\Scripts\python.exe -m hatch.cli session new --cwd D:\my_project
# → 新对话已创建: f7e8d9c0a1b2

# 4. 切回旧对话
venv\Scripts\python.exe -m hatch.cli session use --cwd D:\my_project a1b2c3d4e5f6

# 5. 查看所有对话
venv\Scripts\python.exe -m hatch.cli session list --cwd D:\my_project
#   a1b2c3d4e5f6 *
#     任务: 写 app.py
#     轮次: 2  状态: success
#   f7e8d9c0a1b2
#     任务: 新对话
#     轮次: 0  状态: active
```

### `key` — 凭据管理

```powershell
# 录入
venv\Scripts\python.exe -m hatch.cli key set                # 默认 deepseek
venv\Scripts\python.exe -m hatch.cli key set --provider glm

# 查看状态
venv\Scripts\python.exe -m hatch.cli key status
#   deepseek: ****abcd
#   glm: ****efgh

# 替换
venv\Scripts\python.exe -m hatch.cli key rotate              # 默认 deepseek
venv\Scripts\python.exe -m hatch.cli key rotate --provider glm

# 清除
venv\Scripts\python.exe -m hatch.cli key clear               # 默认 deepseek
venv\Scripts\python.exe -m hatch.cli key clear --provider glm
```

Key 存储在系统凭据管理器（Windows Credential Manager），不在代码或日志中出现明文。

## 配置文件 `hatch.yaml`

```yaml
llm:
  provider: deepseek
  model: deepseek-v4-pro
  api_base: https://api.deepseek.com
  max_tokens: 4096
  temperature: 0.1

loop:
  max_rounds: 3           # 最大修正轮次
  max_total_tokens: 100000

tools:
  enabled:
    - file_reader
    - file_writer
    - shell_executor
    - test_runner
    - linter
    - type_checker
  shell_timeout: 30
  test_timeout: 120

feedback:
  max_rounds: 3
  loop_detection: true

memory:
  max_entries: 100
```

## 目录结构

工作目录下 Hatch 的持久化文件：

```
D:\my_project\
├── app.py                    # 你的代码
├── .hatch/                   # Hatch 内部数据
│   └── sessions/
│       ├── index.json        # 会话索引（最新会话按 updated 排序）
│       ├── a1b2c3d4e5f6.json # 会话历史
│       └── f7e8d9c0a1b2.json
└── .hatch_backup/            # 文件修改前的备份
```

## 术语

| 术语 | 含义 |
|------|------|
| 轮次 (round) | Agent 的一次"生成→执行→反馈→修正"完整循环 |
| 会话 (session) | 一个工作目录下的连续多轮对话 |
| 护栏 (guardrail) | 阻止危险命令的安全规则（如拦截 `rm -rf /`） |
| 反馈引擎 | 解析 pytest/flake8/mypy 输出，生成结构化修正策略 |
| HITL | Human-in-the-Loop，审批式人工干预 |
